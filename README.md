# Book-A-Boo

An international literary platform for discovering, reading, and publishing stories.

## Stack
- Next.js 15 / React 19
- TypeScript
- Supabase (planned for authentication, database, and file storage)
- Vercel deployment

## Development
`npm install`
`npm run dev`

## Project status
The first public-facing editorial homepage is being built. Authentication, reader accounts, author tools, and the Supabase data model will be added in subsequent milestones.

Demo story titles and author names currently shown on the homepage are illustrative placeholders, not published user works.
